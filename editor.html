Publishing on GitHub Pages

  1. Create a public repository on GitHub, or open your existing portfolio repository.
  2. Download the website ZIP above and extract it.
  3. Upload the extracted files and assets folder to the root of your repository. Replace existing files when updating.
  4. In repository Settings → Pages, select “Deploy from a branch”, then “main” and “/(root)”, and Save.
  5. GitHub displays your public website address after publishing finishes.

YouTube hosts your videos. Keep audio compressed and frames reasonably sized: GitHub Pages sites have a 1 GB published size limit. Free Pages hosting uses a public repository. Your email and uploaded files will be public.
